# Vintage & Class - Barbearia Premium

Um site de barbearia premium moderno e elegante, desenvolvido com **Next.js**, **TypeScript** e **Framer Motion**.

## 🚀 Tecnologias

- **Next.js** (App Router)
- **TypeScript**
- **Framer Motion** (Animações)
- **Lucide React** (Ícones)
- **Vanilla CSS** (CSS Modules)

## ✨ Funcionalidades

- **Design Premium**: Visual escuro com detalhes em dourado e tipografia sofisticada.
- **Totalmente Responsivo**: Experiência otimizada para Desktop, Tablet e Mobile.
- **Animações Fluidas**: Revelação de seções ao rolar o scroll e efeitos interativos.
- **Seções Completas**:
  - **Hero**: Boas-vindas impactante com CTA.
  - **Serviços**: Listagem de serviços com preços e ícones.
  - **Sobre**: História e estatísticas da barbearia.
  - **Galeria**: Portfólio de trabalhos realizados.
  - **Footer**: Horários, contatos e links sociais.

## 🛠️ Como rodar o projeto

1.  Clone o repositório.
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
4.  Acesse `http://localhost:3000` no seu navegador.
